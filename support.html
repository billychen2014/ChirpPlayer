常见问题

支持哪些格式？
常见视频与音频格式，如 MP4、MKV、MOV、AVI、WebM、MP3、FLAC、AAC、WAV 等（具体取决于内置解码库）。

如何打开文件？
将文件拖入窗口、点击空白处添加、菜单 File → Open File…（⌘O），或右键菜单选择文件。

播放进度会保存吗？
若在设置中开启「续播」，进度会保存在本机，不会上传。

开源许可在哪里查看？
应用菜单 Help → Open Source Licenses…，或仓库内 JiuJiu/Resources/ThirdParty/。

系统要求

  • macOS 15.0 或更高版本
  • Apple Silicon 或 Intel Mac
