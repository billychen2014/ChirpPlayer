About the App

ChirpAudio is a local music and audiobook player. Import audio into the app sandbox, then play with playlists, favorites, equalizer, synced lyrics, and background / Lock Screen controls. No online music-store account is required.

FAQ

How do I add songs?
From the empty state or library, choose Choose Files or Add from Media Library. The file picker supports multiple selection and folders. Imported tracks are stored inside the app.
Why can’t the app scan my whole phone?
iOS does not allow silent full-disk scanning. You must grant access and pick files/folders, or import downloaded items from the Media Library.
APE / WMA / OGG won’t select in Files?
Use the in-app document picker, or select a folder that contains those files. Some system views may not list these formats as “Music,” but the app can import and play them after selection.
Many Media Library tracks are skipped
Only tracks already downloaded on this device can be imported. Apple Music cloud items, DRM-protected content, or items without a local file URL are skipped.
How do lyrics work?
Import a matching .lrc / .txt (select it with the audio, or import lyrics separately). Embedded timed lyrics in the audio file are recognized on import. Full-screen sing-along requires synced lyrics; importing and full-screen are separate flows.
No sound in background / Lock Screen controls missing
Check the Ring/Silent switch, Background App Refresh / audio permissions, and Control Center Now Playing. After using system pickers, wait a moment or change tracks and try again.
Which formats are supported?
Common formats include MP3, M4A, M4B, AAC, FLAC, WAV, OGG, WMA, APE, and more. See in-app format hints for details.
